# FlakeTrace web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show FlakeTrace's real results through the proposal-stage web UI: a Python backend runs `python -m runner diagnose` and serves only the report it writes; a React app shows that report on the nine POC screens, with unbuilt parts greyed and labelled.

**Architecture:** `ui/server.py` (standard-library `http.server`, `127.0.0.1:8765`) starts the CLI as a subprocess, one job at a time; the browser polls the job and reads the schema-validated report. `ui/web/` reuses the POC's look (components, CSS, layout, step rail) but its state and screens are new and read only our report schema, through one mapping file `src/lib/report.ts`.

**Tech Stack:** Python 3.11 (stdlib + `jsonschema` from `eval/requirements.txt`), `unittest`; React 19, Vite 8, TypeScript 5.9, Tailwind 4 (from the POC), Vitest (new).

**Spec:** `docs/03-Design/specs/2026-10-14-ui-design.md` · **Decision:** `docs/03-Design/decisions/ADR-009-ui-over-cli.md`

## Global Constraints

- **The member commits, never the agent** (root `CLAUDE.md` §3). Every "Commit" step = hand M2 the exact cmd commands; M2 reads `git diff --staged` and runs them. Agents run only read-only git.
- Commit title `[M2] ui: …`, body with `Verified:` (real command + result) and trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; stage files by name; one-line cmd form.
- **One PR at the end** (M2's choice, 2026-10-14), from branch `m2/ui`; commits stay one per task.
- Never show a value the tool did not produce. Data comes only from a report file; POC files `src/lib/sim.ts`, `src/data/recorded.json`, `src/lib/certificate.ts`, `src/lib/evidence.ts` and the old screens/state are **not copied**.
- Unbuilt parts: `NOT BUILT YET — PLANNED FOR X` (X from a written source) or `NOT BUILT — NOT IN CURRENT PLAN`; exact strings in Task 5.
- Backend binds `127.0.0.1` only; port 8765; web dev port 5174 with `/api` proxied to 8765.
- Job timeout 600 s; one job at a time; each job's records in a new folder under the system temp directory.
- Exit codes from `runner/cli.py`: 0 report written · 1 tool failed · 2 bad input · 3 no report.
- `POC/` is read-only; nothing in `runner/`, `evidence/`, `eval/`, `fixtures/` or any contract changes.
- Fakes only under `ui/tests/`, docstring-named `FakeCli`; production code never imports them.
- Every test is seen failing before the code that makes it pass.
- Commands below are for Git Bash from the repository root unless marked **cmd** (Windows `py`). In Git Bash on this machine use `py` as well.

## Review Focus

1. **Paths with spaces** — the repo lives under `…\Semester 7\…`; the project path must reach the CLI unsplit → `test_arguments_with_spaces_reach_the_cli_intact` (Task 2).
2. **A timed-out run leaving JVMs running** — killing only the Python parent would orphan the JVMs it started → `test_timeout_also_stops_child_processes` (Task 2).
3. **Non-ASCII CLI output on Windows** — a cp1252 console would crash or garble the message → `test_non_ascii_cli_output_is_kept` (Task 2).
4. **Backend restarted during a run** — polling an unknown job must say so, not hang → `test_unknown_job_is_404_with_a_reason` (Task 3) and the 404 branch in `state.tsx` (Task 6).
5. **Opening a file that is not a FlakeTrace report** — must be refused with a reason → `test_validate` (Task 3) and `recognises a report by its required fields` (Task 5).

"""FlakeTrace web UI backend (ADR-009).

Runs `python -m runner diagnose` as a subprocess, one job at a time, and returns only the report
file the CLI writes, after checking it against eval/schema/report.schema.json. Listens on
127.0.0.1 only. Start it with `py ui/server.py` or `ui/start.cmd`.
"""
import json
import sys
from pathlib import Path
from typing import Optional

REPO = Path(__file__).resolve().parents[1]
if str(REPO) not in sys.path:
    sys.path.insert(0, str(REPO))

from eval.schema_validator import validate_report  # noqa: E402  (needs REPO on sys.path)

HOST = "127.0.0.1"
PORT = 8765
REPORTS = REPO / "eval" / "reports"
FIXTURE = REPO / "fixtures" / "od-fixture"
TOOLS = ("java", "javac", "javap", "mvn")
RUNNER = [sys.executable, "-m", "runner"]
JOB_TIMEOUT_S = 600
TAIL_LINES = 20
MAX_N = 1000


def tail(text: str, lines: int = TAIL_LINES) -> str:
    return "\n".join(text.strip().splitlines()[-lines:])


def report_problem(report) -> Optional[str]:
    """None if `report` is a valid FlakeTrace report, else why not."""
    try:
        validate_report(report)
    except Exception as error:  # jsonschema's ValidationError
        return f"not a valid FlakeTrace report: {getattr(error, 'message', error)}"
    return None


def load_valid_report(path: Path):
    """(report, None) for a schema-valid report file, else (None, why)."""
    try:
        report = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError) as error:
        return None, f"cannot read {path.name}: {error}"
    why = report_problem(report)
    return (None, why) if why else (report, None)


def _cli_error(stderr: str, returncode: int) -> str:
    lines = [line for line in stderr.strip().splitlines() if line.startswith("error: ")]
    return lines[-1][len("error: "):] if lines else f"the CLI exited with code {returncode}"


def job_result(returncode: int, stdout: str, stderr: str, records: Path) -> dict:
    """The job state for one finished CLI run (exit codes from runner/cli.py). Data comes only
    from the report file the CLI wrote, never from its printed summary."""
    output = tail(stdout + "\n" + stderr)
    if returncode == 0:
        reports = sorted(records.glob("*.report.json"))
        if not reports:
            return {"state": "failed", "kind": "invalid_report",
                    "message": "the CLI exited 0 but wrote no report", "output_tail": output}
        report, why = load_valid_report(reports[-1])
        if report is None:
            return {"state": "failed", "kind": "invalid_report", "message": why, "output_tail": output}
        return {"state": "done", "report": report, "report_path": str(reports[-1])}
    if returncode == 3:
        lines = [line.strip() for line in stdout.splitlines()
                 if line.strip().startswith(("No report:", "record:"))]
        return {"state": "failed", "kind": "no_report", "message": "; ".join(lines) or "No report",
                "output_tail": output}
    kind = "input" if returncode == 2 else "tool"
    return {"state": "failed", "kind": kind, "message": _cli_error(stderr, returncode), "output_tail": output}
```

    deadline = time.monotonic() + limit_s

class Busy(Exception):
    """A diagnosis is already running; two runs would share the project's target/ folder."""

    def __init__(self, job: dict):
        super().__init__("a diagnosis is already running")
        self.job = job


def kill_tree(process: subprocess.Popen) -> None:
    """Stop the CLI and the JVMs it started; killing only the CLI would leave the JVMs running."""
    if os.name == "nt":
        subprocess.run(["taskkill", "/F", "/T", "/PID", str(process.pid)], capture_output=True)
    else:
        os.killpg(process.pid, signal.SIGKILL)
    process.wait()


def check_diagnose_request(body) -> Optional[str]:
    """None if `body` is a usable POST /api/diagnose request, else why not."""
    if not isinstance(body, dict):
        return "the body must be a JSON object"
    for key in ("project", "victim"):
        if not isinstance(body.get(key), str) or not body[key].strip():
            return f"{key} must be a non-empty string"
    n = body.get("n", 20)
    if isinstance(n, bool) or not isinstance(n, int) or not 1 <= n <= MAX_N:
        return f"n must be a whole number from 1 to {MAX_N}"
    order = body.get("order")
    if order is not None and (not isinstance(order, list)
                              or not all(isinstance(test, str) and test.strip() for test in order)):
        return "order must be a list of non-empty Class#method strings"
    return None


class Jobs:
    """Runs one diagnosis at a time and keeps every job's result for polling."""

    def __init__(self, runner: Optional[List[str]] = None, timeout_s: float = JOB_TIMEOUT_S, cwd: Path = REPO):
        self.runner = list(runner or RUNNER)
        self.timeout_s = timeout_s
        self.cwd = cwd
        self._lock = threading.Lock()
        self._jobs = {}
        self._running = None

    def start(self, project: str, victim: str, n: int = 20, order: Optional[List[str]] = None) -> dict:
        with self._lock:
            if self._running is not None:
                raise Busy(dict(self._jobs[self._running]))
            records = Path(tempfile.mkdtemp(prefix="flaketrace-ui-job-"))
            args = ["diagnose", "--project", project, "--victim", victim, "--n", str(n), "--records", str(records)]
            if order:
                order_file = records / "order.txt"
                order_file.write_text("\n".join(order) + "\n", encoding="utf-8")
                args += ["--order", str(order_file)]
            command = self.runner + args
            job = {"id": uuid.uuid4().hex[:12], "state": "running", "started": datetime.now().strftime("%H:%M:%S"),
                   "command": subprocess.list2cmdline(command), "records": str(records)}
            self._jobs[job["id"]] = job
            self._running = job["id"]
        threading.Thread(target=self._run, args=(job["id"], command, records), daemon=True).start()
        return dict(job)

    def get(self, job_id: str) -> Optional[dict]:
        with self._lock:
            job = self._jobs.get(job_id)
            return dict(job) if job else None

    def _run(self, job_id: str, command: List[str], records: Path) -> None:
        try:
            result = self._execute(command, records)
        except Exception as error:  # a job must never stay "running" forever
            result = {"state": "failed", "kind": "tool", "message": f"the backend could not run the CLI: {error}",
                      "output_tail": ""}
        with self._lock:
            self._jobs[job_id].update(result)
            self._running = None

    def _execute(self, command: List[str], records: Path) -> dict:
        env = dict(os.environ, PYTHONIOENCODING="utf-8")
        process = subprocess.Popen(command, cwd=self.cwd, env=env, stdout=subprocess.PIPE, stderr=subprocess.PIPE,
                                   text=True, encoding="utf-8", errors="replace",
                                   start_new_session=os.name != "nt")
        try:
            stdout, stderr = process.communicate(timeout=self.timeout_s)
        except subprocess.TimeoutExpired:
            kill_tree(process)
            stdout, stderr = process.communicate()
            return {"state": "failed", "kind": "timeout",
                    "message": f"timed out after {self.timeout_s:g} s; the run and its JVMs were stopped",
                    "output_tail": tail(stdout + "\n" + stderr)}
        return job_result(process.returncode, stdout, stderr, records)
```

REPORT_PATH = re.compile(r"/api/reports/([\w-]+)")
JOB_PATH = re.compile(r"/api/jobs/(\w+)")


def health() -> dict:
    tools = {tool: shutil.which(tool) for tool in TOOLS}
    return {"tools": tools, "missing": [tool for tool, path in tools.items() if path is None],
            "python": sys.version.split()[0], "fixture": str(FIXTURE)}


def list_reports() -> list:
    """The schema-valid reports in eval/reports/; other JSON there (baseline results) is skipped."""
    entries = []
    for path in sorted(REPORTS.glob("*.json")):
        report, _ = load_valid_report(path)
        if report is not None:
            victim = report["victim"]
            entries.append({"name": path.stem, "victim": f"{victim['class']}#{victim['method']}",
                            "outcome": report["outcome"]})
    return entries


def get_report(name: str) -> Optional[dict]:
    if name not in {entry["name"] for entry in list_reports()}:
        return None
    return load_valid_report(REPORTS / f"{name}.json")[0]


class Handler(BaseHTTPRequestHandler):
    def log_message(self, format, *args):  # keep the console for real errors
        pass

    def _send(self, status: int, body) -> None:
        data = json.dumps(body).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)

    def do_GET(self):
        path = self.path.split("?", 1)[0]
        if path == "/api/health":
            return self._send(200, health())
        if path == "/api/reports":
            return self._send(200, list_reports())
        match = REPORT_PATH.fullmatch(path)
        if match:
            report = get_report(match.group(1))
            return self._send(200, report) if report else self._send(404, {"error": "not_found"})
        match = JOB_PATH.fullmatch(path)
        if match:
            job = self.server.jobs.get(match.group(1))
            if job:
                return self._send(200, job)
            return self._send(404, {"error": "not_found", "message": "no such job; the backend may have restarted"})
        self._send(404, {"error": "not_found"})

    def do_POST(self):
        path = self.path.split("?", 1)[0]
        try:
            body = json.loads(self.rfile.read(int(self.headers.get("Content-Length") or 0)) or b"null")
        except ValueError:
            return self._send(400, {"error": "bad_request", "message": "the body is not JSON"})
        if path == "/api/diagnose":
            problem = check_diagnose_request(body)
            if problem:
                return self._send(400, {"error": "bad_request", "message": problem})
            try:
                job = self.server.jobs.start(body["project"].strip(), body["victim"].strip(), body.get("n", 20),
                                             body.get("order"))
            except Busy as busy:
                return self._send(409, {"error": "busy", "message": "a diagnosis is already running",
                                        "started": busy.job["started"], "command": busy.job["command"]})
            return self._send(202, {"job_id": job["id"]})
        if path == "/api/validate":
            problem = report_problem(body)
            return self._send(200, {"valid": problem is None, "message": problem})
        self._send(404, {"error": "not_found"})


def make_server(port: int = PORT, jobs: Optional[Jobs] = None) -> ThreadingHTTPServer:
    server = ThreadingHTTPServer((HOST, port), Handler)
    server.jobs = jobs or Jobs()
    return server


def main() -> None:
    server = make_server()
    print(f"FlakeTrace UI backend on http://{HOST}:{PORT} (Ctrl+C to stop)")
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        pass
    finally:
        server.server_close()


if __name__ == "__main__":
    main()

import { plural } from "./format";

// Mirrors eval/schema/report.schema.json (read-only consumer, ADR-009).
export type TestId = { class: string; method: string };
export type WilsonCount = { successes: number; n: number; confidence: number; lower: number; upper: number };
export type SharedResource = { kind: "static-field"; class: string; field: string } | { kind: "system-property"; key: string };
export type CodeLocation = { class: string; method: string; bytecode_offset: number };
export type FailureSignature = { exception_type: string; message?: string | null; stack_trace: string };
export type OrderExploration = {
  order_given: boolean;
  shuffled_orders_tried: number;
  orders_exhausted: boolean;
  seed_base: number;
  reproducing_seed: number | null;
  infrastructure_failures: number;
};
export type Outcome = "VERIFIED" | "CANDIDATE" | "UNRESOLVED";
export type Report = {
  victim: TestId;
  polluters: TestId[];
  original_failing_order: TestId[];
  reduced_sequence: TestId[];
  reproduction: WilsonCount;
  sequence_any_signature_failures: number;
  victim_alone: WilsonCount;
  shared_resource: SharedResource | null;
  polluter_write_location: CodeLocation | null;
  victim_read_location: CodeLocation | null;
  failure_signature: FailureSignature | null;
  order_exploration?: OrderExploration;
  instrumentation_level: string;
  execution_record_reference: string;
  source_integrity: { passed: boolean; details: string };
  outcome: Outcome;
  unresolved_reason: string | null;
  limitations: string[];
};

const REQUIRED: (keyof Report)[] = [
  "victim", "polluters", "original_failing_order", "reduced_sequence", "reproduction", "sequence_any_signature_failures",
  "victim_alone", "shared_resource", "polluter_write_location", "victim_read_location", "failure_signature",
  "instrumentation_level", "execution_record_reference", "source_integrity", "outcome", "unresolved_reason", "limitations",
];

export const WILSON_FLOOR = 0.7;

const REASON: Record<string, string> = {
  VICTIM_FAILS_ALONE: "the victim also fails when run alone, so no earlier test can be blamed",
  NOT_REPRODUCED: "the failure never reproduced, in the original order or in any shuffled order tried",
  SIGNATURE_MISMATCH: "the sequence failed, but with a different failure than the original",
  INFRASTRUCTURE_FAILURE: "the runs only crashed or timed out; no real failure was observed",
  NO_SUPPORTED_RESOURCE_EVIDENCE: "no shared state of a supported kind (static field or system property) links the polluter to the victim",
  BELOW_CONFIDENCE_THRESHOLD: "the failure does not reproduce reliably enough",
  SOURCE_INTEGRITY_FAILED: "the analysed project's source changed during the run",
};

export type Loc = { at: string; cls: string; offset: number; note: string };

export type ReportView = {
  victim: string;
  outcome: string;
  outcomeTone: "verified" | "candidate" | "unresolved";
  reason: string | null;
  polluters: string[];
  pollutersNote: string;
  originalOrder: string[];
  reducedSequence: string[];
  reproduction: string;
  reproductionBounds: string;
  alone: string;
  aloneBounds: string;
  resource: { name: string; kind: string } | null;
  resourceNote: string;
  write: Loc | null;
  read: Loc | null;
  signature: string;
  stackTrace: string;
  integrity: string;
  integrityPassed: boolean;
  exploration: string;
  instrumentation: string;
  limitations: string[];
};

export const testName = (t: TestId) => `${t.class}#${t.method}`;

export const outcomeText = (r: Report) => (r.outcome === "UNRESOLVED" ? `UNRESOLVED(${r.unresolved_reason})` : r.outcome);

export const outcomeTone = (o: Outcome) => (o === "VERIFIED" ? "verified" : o === "CANDIDATE" ? "candidate" : "unresolved");

export const resourceName = (r: SharedResource) => (r.kind === "static-field" ? `${r.class}.${r.field}` : `System property "${r.key}"`);

const resourceKind = (r: SharedResource) => (r.kind === "static-field" ? "static field" : "system property");

const rate = (c: WilsonCount) => `${c.successes}/${c.n}`;

const bounds = (c: WilsonCount) => `${Math.round(c.confidence * 100)}% Wilson interval [${c.lower.toFixed(3)}, ${c.upper.toFixed(3)}]`;

export function looksLikeReport(x: unknown): boolean {
  return typeof x === "object" && x !== null && !Array.isArray(x) && REQUIRED.every((key) => key in x);
}

function loc(l: CodeLocation | null, owners: TestId[], inside: string, outside: string): Loc | null {
  if (!l) return null;
  const own = owners.some((t) => t.class === l.class && t.method === l.method);
  return { at: `${l.class}#${l.method}`, cls: l.class, offset: l.bytecode_offset, note: own ? inside : outside };
}

function exploration(r: Report): string {
  const e = r.order_exploration;
  if (!e) return "This report does not record how orders were explored.";
  const start = e.order_given ? "The failing order was given with --order. " : "";
  const crashes = e.infrastructure_failures ? ` ${plural(e.infrastructure_failures, "run")} crashed or timed out.` : "";
  if (e.reproducing_seed !== null) {
    return `${start}Reproduced with a shuffled order (seed ${e.reproducing_seed}) after ${plural(e.shuffled_orders_tried, "shuffled order")}.${crashes}`;
  }
  if (e.shuffled_orders_tried === 0) {
    const which = e.order_given ? "given" : "original";
    return r.reproduction.successes > 0
      ? `${start}The ${which} order reproduced the failure; no shuffled orders were needed.${crashes}`
      : `${start}The ${which} order never reproduced the failure; no shuffled orders were tried.${crashes}`;
  }
  const exhausted = e.orders_exhausted ? " Every distinct order was tried." : "";
  return `${start}${plural(e.shuffled_orders_tried, "shuffled order")} tried (seeds from ${e.seed_base}); none reproduced the failure.${exhausted}${crashes}`;
}

export function toView(r: Report): ReportView {
  const reason = r.outcome === "UNRESOLVED" && r.unresolved_reason ? (REASON[r.unresolved_reason] ?? r.unresolved_reason) : null;
  const signature = r.failure_signature;
  return {
    victim: testName(r.victim),
    outcome: outcomeText(r),
    outcomeTone: outcomeTone(r.outcome),
    reason,
    polluters: r.polluters.map(testName),
    pollutersNote: r.polluters.length ? "" : reason ? `No polluter is named: ${reason}.` : "No polluter is named in this report.",
    originalOrder: r.original_failing_order.map(testName),
    reducedSequence: r.reduced_sequence.map(testName),
    reproduction: rate(r.reproduction),
    reproductionBounds: bounds(r.reproduction),
    alone: rate(r.victim_alone),
    aloneBounds: bounds(r.victim_alone),
    resource: r.shared_resource ? { name: resourceName(r.shared_resource), kind: resourceKind(r.shared_resource) } : null,
    resourceNote: r.shared_resource
      ? ""
      : reason
        ? `No shared resource: ${reason}.`
        : "Static analysis found no shared resource of a supported kind (see Limitations on the Certificate step).",
    write: loc(r.polluter_write_location, r.polluters, "written in the polluter test", "written in a method the polluter calls"),
    read: loc(r.victim_read_location, [r.victim], "read in the victim test", "read in a method the victim calls"),
    signature: signature
      ? `${signature.exception_type}${signature.message ? `: ${signature.message}` : ""}`
      : `No failure signature: ${reason ?? "the report has none"}.`,
    stackTrace: signature?.stack_trace ?? "",
    integrity: r.source_integrity.details,
    integrityPassed: r.source_integrity.passed,
    exploration: exploration(r),
    instrumentation: r.instrumentation_level,
    limitations: r.limitations,
  };
}

import type { Report } from "./report";

export type Health = { tools: Record<string, string | null>; missing: string[]; python: string; fixture: string };
export type ReportEntry = { name: string; victim: string; outcome: string };
export type JobKind = "input" | "tool" | "no_report" | "timeout" | "invalid_report";
export type Job = {
  id: string;
  state: "running" | "done" | "failed";
  started: string;
  command: string;
  records?: string;
  report?: Report;
  report_path?: string;
  kind?: JobKind;
  message?: string;
  output_tail?: string;
};
export type DiagnoseRequest = { project: string; victim: string; n: number; order?: string[] };

export const BACKEND_DOWN = "Backend not running. Start ui\\start.cmd, then press Check again.";

export class ApiError extends Error {
  status: number;
  body: Record<string, unknown>;
  constructor(status: number, body: Record<string, unknown>, message: string) {
    super(message);
    this.status = status;
    this.body = body;
  }
}

export const isBackendDown = (e: unknown) => e instanceof ApiError && e.status === 0;

async function call<T>(path: string, init?: RequestInit): Promise<T> {
  let res: Response;
  try {
    res = await fetch(`/api/${path}`, { cache: "no-store", ...init });
  } catch {
    throw new ApiError(0, {}, BACKEND_DOWN);
  }
  const body = (await res.json().catch(() => null)) as Record<string, unknown> | null;
  // The Vite dev server answers without JSON when the backend behind /api is not running.
  if (body === null) throw new ApiError(0, {}, BACKEND_DOWN);
  if (!res.ok) throw new ApiError(res.status, body, String(body.message ?? body.error ?? `HTTP ${res.status}`));
  return body as T;
}

const post = <T,>(path: string, data: unknown) =>
  call<T>(path, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(data) });

export const api = {
  health: () => call<Health>("health"),
  reports: () => call<ReportEntry[]>("reports"),
  report: (name: string) => call<Report>(`reports/${encodeURIComponent(name)}`),
  diagnose: (req: DiagnoseRequest) => post<{ job_id: string }>("diagnose", req),
  job: (id: string) => call<Job>(`jobs/${encodeURIComponent(id)}`),
  validate: (report: unknown) => post<{ valid: boolean; message: string | null }>("validate", report),
};

import { createContext, useCallback, useContext, useEffect, useMemo, useRef, useState, type ReactNode } from "react";
import { api, ApiError, type DiagnoseRequest, type Health, type Job } from "./lib/api";
import { outcomeText, resourceName, testName, type Report } from "./lib/report";
import { plural, shortName } from "./lib/format";

export type StepId = "source" | "target" | "diagnosis" | "result" | "graph" | "repair" | "verify" | "evosuite" | "export";

export const STEPS: { id: StepId; label: string }[] = [
  { id: "source", label: "Source" },
  { id: "target", label: "Target" },
  { id: "diagnosis", label: "Diagnosis" },
  { id: "result", label: "Certificate" },
  { id: "graph", label: "Evidence graph" },
  { id: "repair", label: "Repair" },
  { id: "verify", label: "Verify" },
  { id: "evosuite", label: "EvoSuite" },
  { id: "export", label: "Export" },
];

export type Loaded = { report: Report; from: string; validated: boolean };
export type Form = { project: string; victim: string; n: number; order: string };

export type State = {
  step: StepId;
  health: Health | null;
  healthError: string | null;
  form: Form;
  loaded: Loaded | null;
  job: Job | null;
  jobStartedAt: number | null;
  jobError: string | null;
};

const NEEDS_REPORT: StepId[] = ["diagnosis", "result", "graph", "export"];
const POLL_MS = 2000;

export const canVisit = (step: StepId, s: State) => !NEEDS_REPORT.includes(step) || s.loaded !== null;

export function summary(step: StepId, s: State): string {
  const r = s.loaded?.report;
  switch (step) {
    case "source":
      return s.healthError ? "Backend not running" : !s.health ? "Checking tools" : s.health.missing.length ? `Missing: ${s.health.missing.join(", ")}` : "Tools found";
    case "target":
      return s.job?.state === "running" ? "Diagnosis running" : r ? shortName(testName(r.victim)) : "Choose the failing test";
    case "diagnosis":
      return r ? plural(r.polluters.length, "polluter") : "No report yet";
    case "result":
      return r ? outcomeText(r) : "No report yet";
    case "graph":
      return r ? (r.shared_resource ? resourceName(r.shared_resource) : "No shared resource") : "No report yet";
    case "export":
      return r ? "Report JSON" : "No report yet";
    default:
      return "Not built";
  }
}

const orderLines = (text: string) => text.split(/\r?\n/).map((line) => line.trim()).filter(Boolean);

type Store = {
  s: State;
  go: (step: StepId) => void;
  setForm: (patch: Partial<Form>) => void;
  load: (loaded: Loaded) => void;
  diagnose: () => void;
  refreshHealth: () => void;
};

const initial: State = {
  step: "source",
  health: null,
  healthError: null,
  form: { project: "", victim: "", n: 20, order: "" },
  loaded: null,
  job: null,
  jobStartedAt: null,
  jobError: null,
};

const StoreContext = createContext<Store | null>(null);

export function StoreProvider({ children }: { children: ReactNode }) {
  const [s, setState] = useState<State>(initial);
  const current = useRef(s);
  current.current = s;
  const alive = useRef(true);
  // Set on every mount: StrictMode mounts twice in development, and a flag left false would drop poll results.
  useEffect(() => {
    alive.current = true;
    return () => {
      alive.current = false;
    };
  }, []);

  const set = useCallback((patch: Partial<State>) => setState((prev) => ({ ...prev, ...patch })), []);
  const go = useCallback((step: StepId) => setState((prev) => (canVisit(step, prev) ? { ...prev, step } : prev)), []);
  const setForm = useCallback((patch: Partial<Form>) => setState((prev) => ({ ...prev, form: { ...prev.form, ...patch } })), []);
  const load = useCallback((loaded: Loaded) => setState((prev) => ({ ...prev, loaded, step: "diagnosis" })), []);

  const refreshHealth = useCallback(() => {
    set({ health: null, healthError: null });
    api
      .health()
      .then((health) => set({ health, healthError: null }))
      .catch((e: Error) => set({ health: null, healthError: e.message }));
  }, [set]);

  useEffect(refreshHealth, [refreshHealth]);

  const poll = useCallback(
    function poll(id: string) {
      api
        .job(id)
        .then((job) => {
          if (!alive.current) return;
          if (job.state === "running") {
            set({ job });
            setTimeout(() => poll(id), POLL_MS);
          } else if (job.state === "done" && job.report) {
            setState((prev) => ({ ...prev, job, loaded: { report: job.report!, from: `Live run: ${job.report_path}`, validated: true }, step: "diagnosis" }));
          } else {
            set({ job });
          }
        })
        .catch((e: Error) => {
          if (!alive.current) return;
          const restarted = e instanceof ApiError && e.status === 404;
          set({ job: null, jobError: restarted ? "The backend restarted, so this run's result is lost. Start the diagnosis again." : e.message });
        });
    },
    [set],
  );

  const diagnose = useCallback(() => {
    const { form } = current.current;
    const order = orderLines(form.order);
    const req: DiagnoseRequest = { project: form.project.trim(), victim: form.victim.trim(), n: form.n, ...(order.length ? { order } : {}) };
    set({ job: null, jobError: null });
    api
      .diagnose(req)
      .then(({ job_id }) => {
        set({ jobStartedAt: Date.now(), job: { id: job_id, state: "running", started: "", command: "" } });
        poll(job_id);
      })
      .catch((e: Error) => {
        const busy = e instanceof ApiError && e.status === 409;
        set({ jobError: busy ? `A diagnosis is already running (started ${String((e as ApiError).body.started)}).` : e.message });
      });
  }, [poll, set]);

  const value = useMemo(() => ({ s, go, setForm, load, diagnose, refreshHealth }), [s, go, setForm, load, diagnose, refreshHealth]);
  return <StoreContext.Provider value={value}>{children}</StoreContext.Provider>;
}

export function useStore() {
  const store = useContext(StoreContext);
  if (!store) throw new Error("useStore must be used inside StoreProvider");
  return store;
}
