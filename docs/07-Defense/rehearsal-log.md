## Self-scoring rubric

Use this rather than "it felt fine".

| Score | Meaning |
| --- | --- |
| 0 | Could not answer |
| 1 | Answered, but wrong or unsupported |
| 2 | Answered correctly but rambled past three sentences |
| 3 | Answered, evidenced, limitation stated, **stopped** |
| −1 | **Deferred to a teammate** — worse than a wrong answer |

Target before the defence: **3 on everything in sections 3, 7 and 13; no −1 anywhere.**

## Recurring failure modes to watch for

- [ ] Softening the POC result into "mixed" or "inconclusive"
- [ ] Saying "automatically fixing" about CDR
- [ ] Saying commercial products "cannot" do this, rather than "their documentation does not describe it"
- [ ] Claiming the dataset is ready
- [ ] Saying "minimum" instead of "1-minimal"
- [ ] Presenting a `POLICY` threshold as a published finding
- [ ] Presenting the Wilson interval as a probability the diagnosis is correct
- [ ] Saying "studied" a baseline tool when you mean "read the paper"
- [ ] Answering a fourth sentence
