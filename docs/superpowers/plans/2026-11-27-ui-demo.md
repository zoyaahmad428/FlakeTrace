# UI Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the web UI runs every option the Final demo needs, opens committed bundles with a fresh `verify`, checks a
bundle folder by path, says how a failure was reproduced, and labels only what is true.

**Architecture:** `ui/server.py` stays a thin front end over the CLI (ADR-009): new request fields map one to one to
CLI flags; two read-only bundle endpoints call `eval.bundle.verify_bundle`. The frontend derives every displayed fact
from the report itself (one rule, in `report.ts`), so a committed bundle and a fresh run read the same way.

**Tech Stack:** Python 3.11 `http.server` + `unittest`; React 19 + TypeScript + Vite, `vitest`.

**Spec:** `docs/superpowers/specs/2026-11-27-ui-demo-design.md`

## Global Constraints

- The UI never writes into the repository; a UI run's bundle goes into the job's own folder (`records / "bundles"`).
- Option names and defaults are the CLI's: search `order`, scope `module`, policy `original`, seed `0`, shuffles `31`,
  no budget, lifecycle `class-grouped` and workspace `copy` (read-only).
- Server refusals equal the CLI's: `search=pairs` or `scope=package` with an `order` → 400 with the CLI's wording.
- `verify` on a committed bundle runs when it is opened, never cached.
- `nosim.test.ts` and every existing test keep passing; no change outside `ui/` and `docs/`.

## Review Focus

1. A bundle name holds `#` (every name does): the frontend URL-encodes it; `GET /api/bundles/<name>` decodes it. (Task 2, 5)
2. `/api/bundles/../x`, an absolute path or an unknown name → 404, never a file outside `eval/bundles/`. (Task 2)
3. `POST /api/check-bundle` with a missing folder or a non-bundle folder → 200 with `ok: false` and the reason, not a 500. (Task 2)
4. Budget fields left empty in the form are sent as absent, not `0` or `""`. (Task 4)
5. A pre-W35 report (no `reproduced_by`) with `order_given: true` reads "given order", never "never reproduced". (Task 3)
